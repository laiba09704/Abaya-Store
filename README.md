# Abaya Store

A simple PHP-based web application for an Abaya Store. This project is developed for learning purposes to understand backend development, database integration, and basic web design.

## Project Description

Abaya Store is a basic e-commerce system where users can view products and manage product data (if admin features are included). It demonstrates CRUD operations using PHP and MySQL.

## Features

- Product listing
- Product detail view
- Add, edit, delete products (if admin module exists)
- MySQL database integration
- Basic HTML and CSS interface

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Setup Instructions

1. Install XAMPP and start Apache and MySQL  
2. Place the project folder inside `htdocs`  
   `C:\xampp\htdocs\abaya_store`  
3. Open phpMyAdmin and create a database  
4. Import the project SQL file (if available)  
5. Run the project in browser:  
   `http://localhost/abaya_store`
